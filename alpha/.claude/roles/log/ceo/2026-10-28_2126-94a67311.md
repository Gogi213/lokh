Окно на скриншоте не подходит: среды в нём работают на серверах Anthropic. Claude на сервер счёта можно поставить одним из трёх способов:

**1. SSH-подключение в Claude Desktop — самый простой.** Вкладка Code работает прямо на сервере.
1. Во вкладке Code откройте выбор среды под полем ввода и нажмите **New environment**.
2. Перейдите на вкладку **SSH**, затем **Host** → **Add SSH connection…**.
3. Заполните: хост `root@89.163.242.211`, порт 22, ключ `~/.ssh/id_rsa`, папку для рабочих копий, например `~/worktrees`.
4. Нажмите **Add SSH connection**, выберите папку на сервере и нажмите **Create environment**.

Claude Code приложение поставит на сервер само, в `~/.claude/remote/`. На сервере должен быть включён SFTP (`Subsystem sftp` в `sshd_config`). Совет: заведите для Claude отдельного пользователя, а не root.

**2. Сервер как «своя» облачная среда (self-hosted)** — только на тарифах Team или Enterprise, в бета-версии.
1. Включите в https://claude.ai/admin-settings/cloud-environments пункт **Allow self-hosted environments**.
2. Там же нажмите **New** и скопируйте ключ среды.
3. На сервере запустите:

```bash
claude self-hosted-runner --environment-secret-file /etc/claude/environment-secret --base-dir /srv/claude-runner
```

Сетевые секреты из вашего окна к такой среде не применяются.

**3. Remote Control.** Ставите Claude Code на сервер, выполняете `claude remote-control` внутри `tmux` и управляете с claude.ai/code или с телефона.

Подробности — в документации: [desktop.md](https://code.claude.com/docs/en/desktop.md) (раздел про SSH) и [self-hosted-environments](https://code.claude.com/docs/en/self-hosted-environments).

## 1. Вопрос
Даёт ли отрыв цены Gate-фьюча от середины DEX-пула исполнимый край (нетто после тарифа, очереди, задержки, фандинга), и кто сходится (Gate к DEX / DEX к Gate / не сошлось)? Два семейства: (S) схождение по отрыву, (Y) «ёршик» — двусторонние мейкер-котировки Gate, ведомые линией DEX.

## 2. Данные (только событийные)
- DEX: событие = своп (время блока/слота; суб-секундный лаг не измерить — оговорка). Цена DEX = **середина пула после свопа**: v3/v4 — sqrtPriceX96, v2 — Sync, Solana — swaps3 (дедуп) + состояние пула; нет середины → цена исполнения ± ½ комиссии пула против направления, метка `mid_src`. Возраст цены DEX ≤ A_dex = 60 с, результат по слоям возраста (≤5, ≤15, ≤60 с).
- Gate фьюч: gev2 `/data/tk0402/gev2/<COIN>/<час>.npy` (t_ms, bid, ask, bq, aq — объёмы лучших есть), сделки мс; дыры (15, 16, 19–21.10; нет файла / .n < 100) — вне. Gate-цена на t = последнее событие книги ≤ t, возраст ≤ A (R1: главное A = 5 с; 1, 30 — чувствительность).
- USD-ноги: стейблы = 1; нативные (WBNB/WETH/WSOL) — середина gev2 той же монеты-котировки на t по тому же правилу A.
- Окно: 15–22.10 (8 сут., дни отдельно) для всех; для 13 монет практиков дополнительно 01.09–14.10 (TK-387/389) там, где есть событийный gev2 (иначе — только окно 15–22.10; Gate до 14.10 в gev2 нет → не используем сделки-посекундно, помечаем «нет данных»).

## 3. Монеты и классы
- Класс P: 13 монет практиков (AGENCY, ALLINU, CLAUDIA, EMBER, FONE, GT, HOOKED, KIMCHI, LAPTOP, PAID, SI, STAMP, SUE) + Q — отдельно, по каждой монете отдельной строкой.
- Класс G: все монеты Gate фьюч с пулом и событийным gev2 (список — из coverage TK-407/402), без пулов-обёрток (сеть пула ≠ родная), токенизированных акций, тикеров с оборотом фьюча 0. Один пул на монету — с наибольшей ликвидностью в $ за окно; прочие — только сверка базиса.
- Класс H (тяжеловесы, отрицательный контроль): BTC/ETH/SOL/BNB и др. — отдельно, в агрегат G не входят.
- Порог ликвидности не назначается: результат по терцилям ликвидности пула.

## 4. Семейство S — схождение
- Отрыв d(t) = ln(mid_Gate(t)/mid_DEX(t)) − базис. Базис = медиана за предыдущие 24 ч по **событиям пары** (без заглядывания, обновление только по завершённому), рядом — сырой отрыв (оговорка: часы без истории — вне).
- Вычисляется только в моменты событий (своп DEX либо изменение BBO Gate), значение «другой стороны» — по правилу возраста; ячейки без обеих сторон в пределах A/A_dex — нет события.
- Формы входа (каждая — отдельное испытание): (а) первое пересечение T; (б) разворот — вход, когда |отрыв| сократился на долю r=0,25 от пика (пик за эпизод); (в) мейкер-лимит Gate на стороне схождения. T ∈ {1, 2, 3, 5} %. Выход: сход до T/2 или 0; таймаут 5 мин / 30 мин / 2 ч / 8 ч. Сетка = 3×4×2×4 = 96 клеток на монету; число испытаний в отчёт, поправка Холма по семейству.
- Вход (а),(б): рыночный по книге gev2 на t+L, L ∈ {0, 100, 250, 500} мс (L по умолчанию 250 — главное; остальные чувствительность), цена — лучший уровень на t+L (по возрасту A), если объём на лучшем < размера (размер — 1 лот = минимум; кроме того, грубая оценка размера $ по объёму лучшего: доля исполнимого) → вход по следующему уровню невозможен (глубже уровней в gev2 нет) → событие отброшено, счётчик drop_size. Вход «+10 с» (B10) **запрещён**, выход тоже с задержкой L, не 0 с.
- Мейкер (в): очередь по потоку изменений gev2 (make/take на нашем уровне: объём впереди = bq/aq на постановке, убывает принтами takes; отмены впереди — оценка сверху/снизу двумя режимами: «ничего не отменяется», «отменяется пропорционально»), задержка постановки L, заявка живёт до ухода уровня за нас/дедлайна. Сторона и двойной счёт — как в TK-391 (верно).
- Тариф: Gate VIP0 фьюч мейкер 2 бп, тейкер 5 бп (+ со скидкой владельца 35 % кэшбэком: 1,3 / 3,25) — оба набора считаются, главный VIP0 без скидки. Фактический спред — из gev2 (не константа).
- Фандинг: расчёты Gate по временам расчёта 00/08/16 UTC по фактическим значениям API (tk402-funding-fetch); сбой API → эпизод помечается `fund_na` и **не** считается нулём (B11); итог — без таких эпизодов и с ними отдельно.
- Выход по таймауту/сходу — по книге на t+L, лучший уровень противоположной стороны.
- Разложение эпизода (п.9 аудита): ход Gate и ход DEX (по середине) до выхода; доля «Gate пришёл» / «DEX пришёл» / «не сошлось».
- Контроль: случайные моменты той же монеты-суток, тот же знак отрыва и длительность, вход по тому же правилу (5 случайных на эпизод, сид [409, форма, T, монета]); край = эпизод − контроль.

## 5. Семейство Y — «ёршик»
- Единица: монета-сутки. Двусторонние мейкер-котировки Gate вокруг линии: линия = середина DEX (после свопа, возраст ≤ A_dex), котировки bid = line·(1−k), ask = line·(1+k), k ∈ {0,2; 0,5; 1} % (как TK-385), пересчёт при каждом новом событии DEX (не чаще 1 раза на 250 мс — L), T (макс. удержание) ∈ {300, 1800} с, формы sym/asym/spread как TK-385.
- Заполнение — **только** по потоку сделок/изменений gev2 с очередью (как S-(в), LOTX=1 — заполняет ≥1 лот, объём впереди учитывается), никакого «любой принт заполняет» (D4), никакого BBO того же корзины (D1/D5/B9). Принудительный выход — рыночный на t+L по книге, с проскальзыванием по объёму лучшего уровня (иначе drop_size). Позиция ±1, встречная заявка снимается после заполнения.
- Тариф и фандинг — как §4 (B8: bid/ask из книги событийно, не ffill 60 раздельно; тариф по набору, не константа).
- Проверка нуля: сдвиг линии DEX +3 ч (отрицательный контроль) и нуль MA1 (скользящая средняя Gate) — отдельными строками; ожидание из TK-391: без заглядывания Q ≈ −16 бп/круг; сверка с этим числом — проба.

## 6. Метрики и правило вердикта (заморозка)
- Главная метрика (R4 по аналогии): нетто бп/круг (VIP0, L=250 мс, A=5 с) за вычетом контроля; тест — кластерный по монетам (класс G), t среднего, df = монет − 1; для класса P — по каждой монете: n, нетто, интервал блочным бутстрапом по монето-суткам, эфф. N по монето-суткам (R6).
- Семейство Холма: форма(3)×T(4)×выход(2)×таймаут(4) для S + k(3)×T(2)×форма(3) для Y, по классам P и G отдельно; α=0,05; монеты в семейство не входят; L ≠ 250, A ≠ 5, скидка — вне семейства.
- Правило: «край есть» — нетто > 0 с интервалом выше 0 после Холма, плюс знак в ≥ 6/8 суток и устойчивость при L=500 мс. Иначе «края нет в области {класс, окно 8 сут., формы}». «Края нет» — только после аудита метода Судьёй; торговых прогнозов нет.
- Месяцы: окно одно, вывод не сильнее одного окна (для 13 монет — 01.09–14.10 по неделям, если gev2 покроет).
- Размер: наряду с 1 лотом — доля эпизодов с достаточным объёмом лучшего ($ объёма на лучшем ≥ 100/1000/10 000 $) по монете.

## 11. Правки Судьи V1–V8 (reviews/tk409-p30-protocol-2026-10-26.md) и критерий владельца 26.10 — внесены 26.10, обязательны; при расхождении главнее §11

- **V1:** главное L = 250 мс, A = 5 с. **A — живость потока монеты по R1 П-29**: последняя любая запись gev2 монеты ≤ A (час без записей — дыра), а не возраст последнего изменения BBO; §2 читать так. Метки gev2 квантованы 0,1 с: L = 0 и 100 мс различимы на 1 тик (оговорка в отчёте).
- **V2:** очередь — два режима; **вердикт — по пессимистичному** («ничего не отменяется», очередь впереди съедается только принтами); «пропорционально» — чувствительность вне семейства.
- **V3:** 01.09–14.10 (gev2 нет) **исключено** из вердикта и N; в отчёте строка «нет данных», без чисел. §2 (сделки мс вместо книги) и §6 (недели 01.09–14.10) — отменены.
- **V4:** базис — окно 24 ч без заглядывания, **медиана взвешенная по длительности** (значение живёт до следующего события пары), не по числу событий; сырой отрыв рядом; первые сутки без истории — вне, счётчик.
- **V5:** Холм отдельно по классам P и G: S 3×4×2×4 = 96 + Y 3×2×3 = 18 → **114 на класс**. H — не тестируется, только контроль; «край» в H = подозрение на дефект метода, разбор до вердикта. Утверждение про отдельную монету P — с поправкой ещё ×13; главный тест P — кластерный по 13 монетам (df = 12).
- **V6 (главные клетки, до счёта):** **S** — форма (а), T = 2 %, выход до T/2, таймаут 2 ч (клетка вердикта TK-386/388 по Q: net +79, n = 52); **Y** — Q, k = 0,2 %, T = 300 с, sym (клетка TK-385). Итог отчёта — по главной клетке (класс P, кластерно); Холм — по семейству; лучшая клетка — не итог.
- **V7:** дыры — часы, не сутки. Сутки годные, если у монеты ≥ 12 часов вне дыр. Правило «знак» — в ≥ 75 % годных суток при годных ≥ 4; иначе «мало данных», не «край есть/нет». Сутки — все 8 с индексами, годные помечены. Заменяет «≥ 6/8» из §6.
- **V8:** главная — только события с настоящей серединой пула (sqrtPriceX96 / Sync / swaps3 + состояние); запасной `mid_src` «исполнение ± ½ комиссии» — чувствительность, доля по монетам в отчёт.
- **Критерий владельца (CEO 26.10 03:55):** главный показатель — **валовый ход, бп/круг, до комиссий**; комиссия (2 × мейкер Gate со скидкой 35 % = 2 × 1,3 = 2,6 бп/круг; VIP0 2/5 и тейкер со скидкой 1,3/3,25) — справочными строками. Спред вычитается только для ног, исполненных по рынку (формы (а),(б) и принудительный выход) — это цена исполнения по книге, не комиссия. Исполнимость лимиток **не упрощается** (очередь по gev2, пессимистичная, принт через цену, задержка L) — иначе бесплатный спред, как в «ёршике» TK-391. Холм, контроль, бутстрап, дни/монеты, drop_size — как выше, но на валовом ходе. Отчёт показывает рядом нетто-после-комиссии.
- **Проба (§7) дополнительно:** отброс по V7 (годные сутки), по V4 (без истории базиса), drop_size; 3 эпизода руками (своп: блок/время/середина; строки gev2 на t и t+L входа/выхода; очередь мейкера) — совпадение с выводом скрипта (`*-manual.txt`); валовое и нетто рядом.

#!/usr/bin/env python3
"""TK-409 П-30 §4 (с §11): схождение Gate-фьюча к DEX ПО СОБЫТИЯМ, форма (а) — первое пересечение, рыночный вход/выход по книге gev2.
Запуск (calc): GEV=/data/tk0393/tk401/gev2all /data/tk0380/npvenv/bin/python tk409-ev-conv.py COIN MIDCSV OUTPREFIX
MIDCSV = ts(с),block,logidx,price (как TK-401/407). Окно 15–22.10 (8 сут.). Событие = своп DEX или запись gev2; значение другой стороны — только в пределах возраста.
V1: A = живость потока gev2 (последняя любая запись <= A, час не дыра); цена DEX — своп не старше 60 с. V4: базис = медиана по ВРЕМЕНИ (сетка 10 с) за предыдущие 24 ч, обновляется раз в час
по завершённому; первые сутки без истории — вне. Отрыв dev = ln(Gate mid / цена DEX) - базис. Вход при первом |dev| >= T (до этого |dev| < T или состояние невалидно); позиция против отрыва,
рыночно на t+L по лучшему уровню (bid/ask) — спред вычтен ценой исполнения; qty лучшего < 1 лота -> drop_size. Выход: |dev| <= T*xf (xf = 0,5 или 0) на событии, иначе таймаут; рыночно на t_выхода+L.
Контроль: 5 случайных валидных событий той же монеты-суток с тем же знаком dev и той же длительностью удержания; край = эпизод - контроль.
Валовый ход = по ценам исполнения (спред внутри), до комиссий; нетто: тейкер VIP0 2*5 = 10 бп, со скидкой 2*3,25 = 6,5 бп; справочно 2*мейкер со скидкой 2,6 бп. Фандинг: флаг fund_cross (расчёт 00/08/16 UTC внутри удержания), сбой не нуль.
Выход: OUTPREFIX-cells.csv, OUTPREFIX-counts.csv, OUTPREFIX-eps.csv (главная клетка), OUTPREFIX-manual.txt."""
import sys, os, glob, datetime as dt
import numpy as np
coin, midf, outp = sys.argv[1:4]
VIS = int(sys.argv[4]) if len(sys.argv) > 4 else 1000  # судья 26.10: своп с меткой ts(с) известен с tv = ts*1000 + VIS (главная 1000, чувствительность 2000/3000)
D0 = 1792022400 * 1000; ND = 8; DEND = D0 + ND * 86400000; H = 3600000; DAY = 86400000
GEV = os.environ.get('GEV', '/data/tk0393/tk401/gev2all')
TRS = [0.01, 0.02, 0.03, 0.05]; XFS = [0.5, 0.0]; TOS = [300, 1800, 7200, 28800]
LS = [0, 100, 250, 500]; AS = [1000, 5000, 30000]; A0, L0 = 5000, 250
MAIN = (0.02, 0.5, 7200)
TAKER_V, TAKER_D, MAKER_D = 10.0, 6.5, 2.6

sw = np.loadtxt(midf, delimiter=',', dtype=np.float64, ndmin=2)
sw = sw[(sw[:, 0] * 1000 >= D0) & (sw[:, 0] * 1000 < DEND)]
sw = sw[np.argsort(sw[:, 0], kind='stable')]
ST = (sw[:, 0] * 1000).astype(np.int64) + VIS; SP = sw[:, 3]; LSP = np.log(SP)

hv = np.zeros(ND * 24 + 2, bool); parts = []
for f in sorted(glob.glob(f'{GEV}/{coin}/??????????.npy')):
    try: n = int(open(f[:-4] + '.n').read())
    except OSError: n = -1
    if n < 100: continue
    d = dt.datetime.strptime(os.path.basename(f)[:-4], '%Y%m%d%H').replace(tzinfo=dt.timezone.utc)
    hi = int(d.timestamp()) // 3600 - D0 // H
    if 0 <= hi < ND * 24: hv[hi] = True; parts.append(np.load(f))
if not parts: sys.exit('SKIP: нет gev2')
a = np.concatenate(parts); a = a[np.argsort(a[:, 0], kind='stable')]
GT = a[:, 0].astype(np.int64); GB, GA, GBQ, GAQ = a[:, 1], a[:, 2], a[:, 3], a[:, 4]
GM = (GB + GA) / 2; GOK = np.isfinite(GM) & (GB < GA)

def gate_at(t, A):
    k = np.searchsorted(GT, t, side='right') - 1; kc = np.clip(k, 0, None)
    hi_t = np.clip((t - D0) // H, 0, ND * 24 - 1); hi_r = np.clip((GT[kc] - D0) // H, 0, ND * 24 - 1)
    ok = (k >= 0) & (t - GT[kc] <= A) & hv[hi_t] & hv[hi_r] & GOK[kc]
    return kc, ok
def dex_at(t):
    k = np.searchsorted(ST, t, side='right') - 1; kc = np.clip(k, 0, None)
    return kc, (k >= 0) & (t - ST[kc] <= 60000)

U = np.unique(np.concatenate([ST, GT[(GT >= D0) & (GT < DEND)]]))
IS_SW = np.isin(U, ST)  # событие-сигнал: своп (tv) либо запись Gate
kd, okd = dex_at(U); LP_U = LSP[kd]
GRID = np.arange(D0, DEND, 10000, dtype=np.int64); kgd, okgd = dex_at(GRID)
SER = {}
for A in AS:
    kg, okg = gate_at(U, A); lg = np.log(np.where(okg, GM[kg], np.nan))
    d_raw = lg - LP_U; ok = okg & okd
    kg2, okg2 = gate_at(GRID, A); dg = np.log(np.where(okg2, GM[kg2], np.nan)) - LSP[kgd]; dg[~(okg2 & okgd)] = np.nan
    bh = np.full(ND * 24, np.nan); nhist = 0
    for h in range(24, ND * 24):  # окно [h-24ч, h) по сетке 10 с; нужно >= 50 % валидных (V4)
        w = dg[(h - 24) * 360:h * 360]; w = w[np.isfinite(w)]
        if len(w) >= 4320: bh[h] = np.median(w)
    b = bh[np.clip((U - D0) // H, 0, ND * 24 - 1)]
    dev = d_raw - b; val = ok & np.isfinite(dev)
    SER[A] = dict(dev=np.where(val, dev, 0.0), val=val, kg=kg, raw=d_raw, lg=lg, nb=int(np.isfinite(bh).sum()))
dayok = [int(hv[d * 24:(d + 1) * 24].sum()) >= 12 for d in range(ND)]  # V7: годные сутки (>= 12 часов вне дыр)
SETTLE = np.array([D0 + d * DAY + k * 8 * H for d in range(ND + 1) for k in range(3)], np.int64)

def px(t, A, q, open_):
    """цена исполнения рыночного хода q (+1 купить / -1 продать) на t: (цена, статус) статус 0 ок, 1 не жив, 2 qty<1"""
    k, ok = gate_at(np.array([t]), A); k = int(k[0])
    if not ok[0]: return np.nan, 1, k
    p = GA[k] if q > 0 else GB[k]; qty = GAQ[k] if q > 0 else GBQ[k]
    return p, (0 if qty >= 1 else 2), k

def run(Tr, xf, TO, L, A, want_eps=False):
    S = SER[A]; dev = S['dev']; val = S['val']; lg = S['lg']
    ab = val & (np.abs(dev) >= Tr); prev = np.r_[True, ~ab[:-1]]
    cand = np.nonzero(ab & prev)[0]
    rng = np.random.default_rng([409, int(Tr * 1e4), int(xf * 10), TO, L, A])
    eps = []; cnt = dict(n_cand=len(cand), drop_hist=0, drop_age=0, drop_size=0, drop_exit_age=0, exit_thin=0, busy=0)
    last = -1; vidx_all = np.nonzero(val)[0]; dayU = (U - D0) // DAY
    for i in cand:
        if U[i] < D0 + DAY: cnt['drop_hist'] += 1; continue  # ровно сутки без истории базиса
        if i <= last: cnt['busy'] += 1; continue
        s = 1 if dev[i] > 0 else -1; q = -s
        pe, st, ke = px(U[i] + L, A, q, True)
        if st == 1: cnt['drop_age'] += 1; continue
        if st == 2: cnt['drop_size'] += 1; continue
        jmax = int(np.searchsorted(U, U[i] + TO, side='right')); j0 = max(i + 1, int(np.searchsorted(U, U[i] + L, side='left')))
        seg = slice(j0, jmax); hit = np.nonzero(val[seg] & (s * dev[seg] <= Tr * xf))[0]
        if len(hit): jx = j0 + int(hit[0]); tx = int(U[jx]); kind = 'exit'
        else: jx = jmax - 1; tx = int(U[i] + TO); kind = 'timeout'
        px_, st2, kx = px(tx + L, A, -q, False)
        if st2 == 1: cnt['drop_exit_age'] += 1; continue
        if st2 == 2: cnt['exit_thin'] += 1
        last = jx
        g = q * (np.log(px_) - np.log(pe)) * 1e4
        # разложение: ход Gate (mid) и DEX (цена) в сторону схождения, бп
        gx = np.log(GM[kx]); gi = lg[i] if np.isfinite(lg[i]) else np.nan
        kdx, okx = dex_at(np.array([tx])); lpx = LSP[int(kdx[0])]
        g_mv = -s * (gx - gi) * 1e4; d_mv = s * (lpx - LP_U[i]) * 1e4
        fund = bool(((SETTLE > U[i] + L) & (SETTLE <= tx + L)).any())
        # контроль: 5 случайных валидных событий той же монеты-суток, тот же знак dev, то же удержание
        pool = vidx_all[(dayU[vidx_all] == dayU[i]) & (np.sign(dev[vidx_all]) == s)]
        cg = []
        for r in (rng.choice(pool, 5) if len(pool) else []):
            p1, s1, _ = px(U[r] + L, A, q, True); p2, s2, _ = px(U[r] + (tx - U[i]) + L, A, -q, False)
            if s1 == 0 and s2 != 1 and np.isfinite(p2): cg.append(q * (np.log(p2) - np.log(p1)) * 1e4)
        eps.append((int(U[i]), int(dayU[i]), s, g, float(np.mean(cg)) if cg else np.nan, kind, tx - int(U[i]), g_mv, d_mv, fund, int(i), jx, ke, kx, 'swap' if IS_SW[i] else 'gate'))
    return eps, cnt

def summ(eps):
    if not eps: return None
    g = np.array([e[3] for e in eps]); c = np.array([e[4] for e in eps]); day = np.array([e[1] for e in eps]); ex = g - c
    okc = np.isfinite(c); days = sorted(set(day.tolist()))
    pd = {d: (int((day == d).sum()), float(g[day == d].mean())) for d in days}
    rng = np.random.default_rng(409); bs = []
    for _ in range(2000):
        pick = rng.choice(days, len(days)); idx = np.concatenate([np.nonzero(day == d)[0] for d in pick]); bs.append(np.nanmean(ex[idx]))
    good = [d for d in days if dayok[d]]; pos = sum(1 for d in good if pd[d][1] > 0)
    src = np.array([e[14] for e in eps]); sp = {}
    for nm in ('swap', 'gate'):
        m = src == nm; sp[f'n_{nm}'] = int(m.sum()); sp[f'gross_{nm}'] = float(g[m].mean()) if m.any() else np.nan; sp[f'excess_{nm}'] = float(np.nanmean(ex[m])) if m.any() and np.isfinite(ex[m]).any() else np.nan
    return dict(**sp, vis=VIS, n=len(g), gross=g.mean(), med=float(np.median(g)), ctrl=float(np.nanmean(c)) if okc.any() else np.nan, excess=float(np.nanmean(ex)), ci_lo=float(np.percentile(bs, 2.5)), ci_hi=float(np.percentile(bs, 97.5)),
                net_v=g.mean() - TAKER_V, net_d=g.mean() - TAKER_D, ref_mk=g.mean() - MAKER_D, hit=float((g > 0).mean()), n_days=len(days), good_days=len(good), pos_good=pos,
                gate_mv=float(np.mean([e[7] for e in eps])), dex_mv=float(np.mean([e[8] for e in eps])), n_fund=int(sum(e[9] for e in eps)), per_day=';'.join(f'{d}:{pd[d][0]}:{pd[d][1]:.1f}' for d in days))

rows = []; crow = []
def do(Tr, xf, TO, L, A, tag):
    eps, cnt = run(Tr, xf, TO, L, A); s = summ(eps)
    crow.append(dict(tag=tag, T=Tr, xf=xf, TO=TO, L=L, A=A, **cnt))
    if s: rows.append(dict(tag=tag, T=Tr, xf=xf, TO=TO, L=L, A=A, **s))
    return eps
for Tr in TRS:

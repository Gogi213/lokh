Когда пользователь задаёт рамки («делаем только P0-P1», «не коммитим, не пушим, проверяем»), делать ровно это: новые идеи (фолбек LLM, своя база мест, экономия токенов) только предлагать и откладывать, правки после критиков — только по багам в собственных изменениях. Мелкие сопутствующие файлы называть явно.

**Why:** пользователь дважды переспросил «помнишь что щас мы делаем тока п0 п1?» и «не коммит пушим проверяем» (2026-10-09).
**How to apply:** перед новой работой сверяться с заявленными рамками; коммит/пуш/деплой — только после явного «да». Связано с [[verger-project]].

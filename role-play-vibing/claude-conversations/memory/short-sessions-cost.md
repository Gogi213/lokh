Владелец спросил, сколько стоила бы разработка по ценам API (14.10.2026): ≈ $112 за день, $171 за V2. В главной сессии
$30.56 из $43.17 — чтение кэша (153 млн токенов, контекст ~700 тыс.); агенты на Sonnet — $49. После ответа сделал клир.

**Why:** критерий 11 бизнес-задачи [[business-task]] — токены на работу, а не на механику; длинная сессия перечитывает
весь разговор на каждом шаге.
**How to apply:** одна сессия — один-два чекпоинта, затем запись в память и клир; тяжёлые замеры и правки — агентам
с узким заданием; не держать в контексте большие выводы (логи, отчёты) — читать хвост или итог. Считалка расхода по
журналам: разбор `~/.claude/projects/<проект>/**/*.jsonl` (usage по message.id) × цены из skill claude-api.

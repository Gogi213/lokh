## Наблюдения

- Внутренние кулдауны и окна: AoE статусов — 0.25 с ICD (шанс 50%, радиус 3 м); взрыв при статусе на игроке — 3 с ICD (радиус 3 м); смена стихии — окно 1.5 с, возврат КД 2 с; крит после уклонения — 3 с; ярость после удара — 5 с (перезапуск при новом ударе); серия прыжков — сброс через 5 с без прыжка; подъём без урона — 10 с; рывок первой минуты — 60 с; обновление золота/кристаллов — 1 с задержка на объединение.
- Стаковые механики: прыжки +15%/каждый (потолок +100%); рывки +5% (потолок +15%); разные стихии +4%/(n−1); безупречные боссы +10% без предела; золото 0.04%/монету (потолок 20%); кристаллы 0.01%/штуку (+2.01% базово); проклятые +3%/+5%/+1%+15HP/…; инвентарь +1%/предмет.
- Общий порог HP «критическое здоровье»: 0.3 (≤). Реликвии на пороге: броня +20%, крит +20%, урон +15%. Реликвия «полный HP» — порог 1.0 (≥).
- Типы модификаторов: большинство «урон +X%» — множ. приоритета 10; шанс крита/броня/скорость анимации/уровни статусов — адд.; «потолок урона» и «шанс крита 100% после уклонения» — «перезапись»; урон крита +800% и −75% — адд. и позднее умножение.
- Условия «все умения»: везде где написано «кроме статусных» — по признаку «статусный эффект»; «кроме базовых и рывка» — по ID умения (содержит Basic / Dash). Список для data-схемы: фильтр умений (все / без статусов / только базовые / только не-базовые / по стихии / только прыжковые).
- Жизненный цикл: большинство реликвий снимают свой мод в деактивации; «деактивация» вызывается и при упаковке в группу (потом активация снова); при выбросе проклятых и т.п. подробности — в 14.
- Уничтожение при выбросе: только у «урон при полном HP» и «безупречные боссы»; обе при получении полностью лечат при каждой активации.
- Хаб-ограничения: только «проклятая реликвия каждого этажа» (hubOnly). Пул/цены — в 09-loot.
- Группы (контейнеры): «пять счётчиков арканов», «пять аур», «пять спутников-таранов» без собственного эффекта; расширяют инвентарь (контейнер = 1 слот, но для «броня от числа реликвий» считается как число частей). Сборка происходит при добавлении второй части: часть вызывает «создание группы», группа забирает части в свой внутренний инвентарь и они снова активируются.
- Группы по эффекту (в других кусках): шансы статусов (6, включает «урон по статусным целям»), иммунитеты (5), сопротивления (5), золото (5: урон/броня от золота и т.д.), «с проклятыми» (3), спутники (5), счётчики арканов (5), ауры (5), призывы (6), скидки (5), локаторы (3), базовая атака (5).
- Параметры data-схемы (поля, общие для многих): hp_threshold (0.3/1.0) + comparison, mod_type (add/mult/late_mult/override), value, per_count + cap, source_count (проклятые / инвентарь / золото / кристаллы / разные стихии / арканы стихии), duration, icd, chance, radius, element, skill_filter, once_per_pickup_effect (полное лечение / очистка инвентаря / выдача золота), debounce_sec (1.0), curse_penalty (второй блок модов).
- Экономические: цены в золото ×1.5 (две реликвии), потеря 5 золота за удар, долг 250 (+ceil 10%/сцену), покупка за HP/кристаллы, 2/3 золота за аркану.
- Кооп: «напарники» (+5/+12.5/+15%), «длительность оглушения босса» (снятие при владении у обоих).

## open_questions

- Реальный смысл «брони» (доля снижения урона?) и приоритетов — определяет 14-stat-modifiers; в каталоге указано как «+X% (адд.)».
- AoE статусов: срабатывает на каждый тик DoT или только на нанесение/наложение? В коде — глобальное событие DoT, момент тика не проверен.
- Спутник-таран: величина урона и параметры префаба неизвестны (в коде только поведение).
- Реликвии с полным лечением при получении (урон при полном HP, безупречные боссы): лечат на каждой активации, в т.ч. при смене этажа/упаковке? Не проверено.
- «Ссуда»: как долг уходит при нулевом золоте; расчёт процентов — каждая загрузка игровой сцены, включая босс-этажи?
- «Баланс арканов»: какие слоты входят (весь массив assignedSkills включая базовую и рывок или только арканы).
- Шкала овердрайва: единицы (0–100), +15 за событие — точное расхождение «ready» (режим активен) и «шкала полная».
- Уровень стихийных статусов у воздуха/воды в «уровень +1» — у воды нет уровня в коде (только огонь/воздух/земля/молния).
- «Платить кристаллами»: условие «проклятых меньше 12» выглядит как копия лимита инвентаря, а не логичной проверки.

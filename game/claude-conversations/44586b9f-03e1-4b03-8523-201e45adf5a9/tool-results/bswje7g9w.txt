# 25 — Интерфейс и HUD

## Цель

Описать каждый экран и элемент HUD: что показывает, когда виден, как реагирует на ввод. Всё читает состояние симуляции и не пишет в него (кроме покупок и обмена слотов, идущих через команды). Тексты — свои, из локализации (спека 27).

## Поведение

### Игровой HUD (на игрока; в коопе два набора, второй сдвинут вправо ≈ 366 px; панель реликвий второго игрока — на +264 px, её 12 иконок заполняются справа налево, индекс 11 → 0; цвет портрета берётся из палитры облика игрока)

1. **Полоса здоровья.** Портрет (цвет по облику) + заливка здоровья + текст «текущее/максимум» целыми. Под заливкой «след урона». **Поведение референса (проверено по коду):** таймер 1.5 с след **не удерживает**. При падении HP, если предыдущий таймер истёк (или не был запущен), след переустанавливается на HP до удара, таймер перезапускается на 1.5 с, но больше нигде не читается. След убывает **каждый кадр сразу** со скоростью 25 ед. HP/с, пока выше текущего HP (игровое время); паузы-удержания нет; вторая рана в окне 1.5 с продолжает текущий след без переустановки. Для полосок боссов то же с таймером 0.4 с (скорость — из префаба, в данных не найдена). **У нас — то же поведение** (след без удержания), таймер 1.5 с не реализуется.
   Порог тревоги: доля HP ≤ 0.3 и > 0 — фон и портрет красятся одним цветом и мигают белый↔красный; значение лерпа 0↔1 растёт со скоростью max(0.3 − доля, 0.1) × 22 за секунду (2.2 при доле ≥ 0.2, до 6.6 у нуля), т.е. параметр — **полуциклы**, полный цикл белый→красный→белый = 2 / скорость. Звук тревоги один раз при входе в зону (сброс при выходе), на экране загрузки не играет. Текст HP — усечение до целого, «текущее/максимум (с модификаторами)».
2. **Шкала ульты** — заливка по доле 0..1; когда готова, цвет пульсирует по альфе 1.0 ↔ 0.4 со скоростью 2.5/с.
3. **Полоска щита** привязана к позиции хёртбокса игрока: видна только при щите > 0, заливка = доля щита. Два вида «пинга» (иконка вспыхивает над игроком, анимация перезапускается с начала): пинг арканы (иконка арканы) и пинг предмета (иконка реликвии). Подсказка воскрешения у умершего: иконка кнопки подтверждения (геймпад — зелёная, клавиатура — «пробел», зашито).
4. **Панель перезарядок: 6 слотов + запасной (седьмой).** Слот: рамка (тип: обычный / фирменный / усиленный), иконка, иконка клавиши слота по схеме ввода, затемнение-оверлей, текст. Состояния: Disabled (нет арканы; иконка-заглушка, клавиша скрыта), Ready (полная яркость, оверлей выключен, рамка заполнена), NotReady (блок по условию: приглушённая иконка альфа 0.6, оверлей полный, текста нет), Cooldown (оверлей-«часы» заливка = остаток/полное, текст = секунды: < 10 с — один знак после запятой, ≥ 10 — целое). Аркана с зарядами: рамка заполняется долей суммарных зарядов; при готовом заряде текст = число зарядов, оверлей зависит от «можно ли использовать»; иначе текст = остаток (задержки между зарядами или перезарядки) в том же формате, заливка оверлея = остаток / (время задержки или полное время). Формат текста: `< 10 с` — один знак («0.0»), **округление, а не усечение** (9.96 → «10.0»); `≥ 10` — целое с округлением (10.4 → «10», 12.6 → «13»). Цвета: готов 160 серый; не готов альфа 60; фирменная (255,204,0); затемнённая клавиша 0.4. **Пинг готовности:** при переходе Cooldown → Ready **и** Cooldown → NotReady (если по окончании КД аркана заблокирована по условию) на HUD над игроком вспыхивает иконка арканы; окно пинга одно на игрока, не чаще раза в 0.5 с; первый пинг возможен через 0.5 с после привязки HUD к игроку. **Запасной (седьмой) слот:** иконка клавиши — кнопка «меню снаряжения» по схеме игрока; фон — фирменный/усиленный/обычный по аркане. Рядом **плитка «карта»**: иконка кнопки «карта»; активна (рамка (160,160,160,255), иконка/текст (1,1,1,0.6)) только в игровой сцене и не в сцене босса, иначе затемнена ((0.4,0.4,0.4,0.6), оверлей включён). Отдельный «пинг предмета» для срабатывания реликвии.
5. **Панель реликвий:** 12 слотов; иконки с состояниями Disabled/Ready/Active — только у реликвий с состоянием; порядок = порядок добавления. Цвета: Disabled — иконка (0.4,0.4,0.4,0.7); Ready — (1,1,1,0.8); Active — иконка (1,1,1,0.8) + подложка (208,247,255,102) и рамка (219,249,255,115); обычная рамка (109,109,109,80), подложка (0,0,0,0.31). Новая реликвия добавляется в состоянии Disabled; **звук при каждой смене состояния** (UI-шина): Active — «активация», Ready — «готов», Disabled — «деактивация»; удаление перестраивает ряд.
6. **Валюты.** Золото и кристаллы — две цифры, видны в игровых сценах и хабе, обновляются каждый кадр; скрыты, когда выключен режим. Счёт кошелька общий для обоих игроков.
7. **Каст-бар** над игроком: маленькая полоса заливки каста (размеры по якорям 0.44–0.56 × 0.7–0.71 внутри рамки бара). Два режима: «заряд» — заливка 0→1 цветом (0, 0.6, 1, 0.8), при 100 % меняется на зелёный и держится до конца каста; «разряд» — заливка 1→0, по завершении гасится. Не создаётся при скрытом интерфейсе; прерывание гасит бар на следующем кадре; сбрасывается при деактивации. Бар следует позиции родителя каждый кадр; при пропавшем родителе уничтожается.
8. **Счётчик врагов (комната боя / элита):** 3 черепа; порог закрытия 30% / 60% / 90% убитых врагов уровня; заливка активного черепа **убывает** от 1 к 0: `1 − (прогресс между порогами)` (для первого: `1 − доля/0.3`); при достижении порога гаснет **самый старший из ещё горящих** (индекс 2, затем 1, затем 0) по анимации; за кадр не более одного; кадр после генерации этажа пропускается. Состояние гашения зеркально (в обратном порядке) передаётся в алтарь и круг активации особой комнаты (18). Сброс при смене сцены; на сценах вне этажей скрыт.
9. **Подсказка над головой** («взаимодействие»): иконка клавиши по схеме игрока у объекта; показывается в триггере, прячется при выходе.
10. **Объявления:** крупный текст с подчёркиванием (название этапа, «победа» 1 с, «бой», комбо 0.75 с). Строка-уведомление: на заданное время (по умолчанию 3 с); в гонке боссов, если другого уведомления нет, каждые 0.5 с показывает общее время (целые секунды).
   - **Параметры объявлений:** название этапа — показ через 0.2 с после загрузки, шрифт 60, удержание 0, с подчёркиванием. «Бой»: шрифт 180, красный, скорость анимации 1.75, толстая линия (масштаб Y 5). «Победа»: шрифт 120, цвет (0.93, 0.85, 0.4), кайма (0.6, 0.41, 0.2), анимация со старта 0.5, удержание 1 с, конфетти: 24 в центре + по 8 слева и справа со сдвигом ±2.5 м. «Комбо»: «N» + текст, красный, шрифт 60, 0.75 с.
   - **Алгоритм:** анимация «появление» занимает первые 30 % времени, затем удерживается кадр 0.55, пока не истечёт длительность; новое объявление при идущем отменяет текущее (пауза 3 кадра). Шрифты ≥ 90 × множитель языка сдвигают подчёркивание вниз на `20 × размер / (90 × множитель)` (корейский — 24 вместо 20).
11. **Цифры урона** — по спеке 03; включаются настройкой «цифры» (26).
12. **Полоски врагов.** Два вида. (а) **Мини-полоска над головой** (только при реликвии «полоски», пул 25): цвет (0.6, 0, 0, 0.8), размер 0.44–0.56 × 0.45–0.46 внутри рамки; показывается для обычных врагов, вошедших в зону-активатор (не для мини-боссов, боссов и тренировочной куклы); активатор включается только на этажах и заново — через кадр после загрузки сцены. (б) **Полоска босса/мини-босса**: имя, заливка, след (п.1, 0.4 с), щит; появляется всегда; прозрачность 0.01 → 1 за 0.25 с и «налив» заливки 0 → полная за 1 с.

### Пауза и подтверждение

13. **Пауза** (кнопка паузы): камера размывается, симуляция и звук остановлены (24), игроки отключены. 4 пункта по кругу: продолжить / выйти на титул (в обучении — в комнату игрока, в музее — «пропустить») / опции / выйти из игры. Навигация вверх-вниз с зацикливанием; выбранный пункт цветом; звук «шаг меню» при смене. Пункты «титул» и «выйти» требуют подтверждения. Повторное нажатие паузы закрывает меню, если фокус на нём (не в опциях). Меню снаряжения блокируется на паузе.
   - **Детали:** подтверждение в меню паузы принимается кнопкой «Подтверждение» **или** клавишей пробел (зашито). Меню открывается по **нажатию** «Меню» и закрывается по **отпусканию** «Меню» или «Отмена». Пауза запрещена: при всех мёртвых, при активном итоге этажа, на экране загрузки (отложенная пауза выставляется после загрузки), в сцене титров; клавиша «Меню» не открывает паузу у клавиатурного игрока в состоянии «Paused» (меню снаряжения/хаб-окно открыто). Отключение устройства основного контроллера ставит паузу в очередь, если меню паузы не открыто. Экран загрузки принудительно закрывает меню паузы. Размытие — включение компонента на камере.
14. **Окно подтверждения:** заголовок + два варианта (отмена сверху, да снизу), по умолчанию выбрана отмена; 4 варианта заголовка (первый/второй/третий/перезапуск — для многошагового подтверждения). Первый кадр после открытия игнорирует ввод.

### Меню снаряжения (клавиша «меню снаряжения», только в Idle/Run)

15. Окно из трёх частей: слоты арканов (6 + запасной), решётка реликвий, облик; внизу инфо-панель с описанием выбранного. Закрывается отпусканием «Отмена» или потерей состояния Idle/Run. Слоты: подтверждение берёт аркану, второе подтверждение меняет местами; нельзя оставить пустым «значимый» (фирменный/ключевой) слот (подсвечен серым). Быстрая замена: удерживать «меню снаряжения» + нажать кнопку слота — слот меняется с запасным (запасной подсвечен зелёным). Решётка реликвий: 6 колонок × 2 видимых ряда, до 30 предметов; навигация по клеткам с «заворотом» в ряду; «Взаимодействие» выбрасывает выбранную реликвию на пол; «Подтверждение» на головном уборе надевает его. Метка категории предмета: атака / защита / разное.
   - **Состояние:** открытие переводит в «Paused» **только игрока** (мир идёт); закрытие — обратно в Idle. Доступно из Idle/Run. Закрытие: повторное нажатие «меню снаряжения», отпускание «Отмена», потеря доступности, быстрая замена (закрывается следующим кадром), блокировка на паузе игры.
   - **«Значимые» арканы** (слот нельзя оставить пустым или заменить): базовая атака, фирменная, рывок. Запасной слот не принимает базовую/фирменную/рывок (звук ошибки). Быстрая замена на значимой аркане — звук ошибки.
   - **Навигация:** порог стика 0.3 на нажатие / 0.2 на отпускание; «лево/право» по 6 слотам с заворотом mod 6; «вниз» из слотов — на запасной (если есть), иначе в решётку реликвий; «вверх» — на панель облика, с неё «вниз» возвращает. Рамка выбора пульсирует по альфе 1 ↔ 0.6 со скоростью 1/с.
   - **Инфо-панель:** имя (золотой #FFCC00) + описание (для арканы с усилением — блок «усиление», 27); флаги арканы (до 5 значков); для реликвий — значок категории. Звуки: открытие/закрытие, «шаг», «снаряжение» при выборе/обмене, «ошибка» при запрете.
   - **Решётка реликвий:** 6 колонок × 2 ряда видимо (якоря: ширина 0.115, отступ слева 0.03, шаг 0.05; высота 0.32, начальный отступ 0.1, шаг 0.12), до 30 предметов. Навигация по рядам с заворотом влево на последнюю клетку ряда (но не за число предметов); «вниз» с последнего ряда — на последнюю клетку; «вверх» из первого ряда — в слоты (индекс колонки переносится, колонка % 6). Инфо: имя, метка «проклятая» красным, для групповых предметов — прогресс «1/N» или строка комплектации, затем описание с динамической добавкой. «Взаимодействие» выбрасывает предмет, выбор смещается на предыдущую клетку; при пустом списке фокус уходит в слоты.
16. **Уведомление о получении/потере:** над игроком (+2.75 м) всплывает иконка, имя, иконка клавиши. Очередь: 20 — только начальная ёмкость, **предела нет**; дубликат определяется только по имени среди **ожидающих** (показываемое сейчас не учитывается). Следующее уведомление начинается, когда текущая анимация проиграна на 80 %. Потеря арканы — анимация и звук «потеря арканы»; потеря реликвии — звук «потеря реликвии».
16б. **Уведомление о разблокировке:** отдельная очередь (ёмкость 20 — не предел), 4 типа: аркана, фирменная, реликвия, облик (палитра облика); заголовок = имя + «разблокировано», подзаголовок по типу. Показ: анимация «появление», удержание 1.5 с после 75 % проигрывания, затем «скрытие». Звук «вступление» — только если очередь пуста и ничего не показывается; звук «выход» — при каждом показе. Очередь и анимация сбрасываются при загрузке уровня.

### Книга арканов (хаб-услуга)

17. Страницы: игрока (4 карты: базовая, рывок, дополнительная, фирменная), стихий (5 стихий + хаос), арканов стихии (2 страницы на стихию, у хаоса 1), ульты (6), карточка арканы (до 5 инфо-карт, 3 вкладки). Фокусы: стихия/ульта/аркана/инфо/вкладка/игрок. Экипировка анимируется переносом карты на страницу игрока. Маркер «новое» на недавно открытых.
   - **Правила экипировки:** аркана со страницы стихии занимает слот по типу: базовая → слот 0, рывок → слот 1, остальные → слот 2 (заменяет любую обычную не-фирменную аркану билда с совпадающим типом); если выбираемая аркана сейчас фирменная — ошибка. Ульта (карточка 4) заменяет фирменную; если она уже во вложенных слотах — меняются местами. Побочные эффекты: профиль сохраняется, **HP восстанавливается до полного**. Анимация: карта поднимается на 180 px со скоростью 900 px/с, затем летит 0.15 с в слот на странице игрока, вспышка (для фирменной — отдельная); звуки «выбор карты», «снаряжение». Листание страниц — звук «шуршание страницы».
18. **Лодаут-стенд:** 6 слотов на каждого игрока отдельно; в слоте сохранены **один облик, одна стартовая реликвия и 4 аркана** (базовая, рывок, обычная, фирменная). Радиус взаимодействия 4 м.
   - **Управление:** вверх/вниз с заворотом 0..5, задержка первого повтора 0.4 с, дальше автоповтор 0.2 с; «Подтверждение» → запрос загрузки, «Взаимодействие» → запрос сохранения (в окне подтверждения по умолчанию «нет»; сохранение в PvP запрещено, звук ошибки). Закрывается по «Отмена» или при удалении игрока дальше 4 м; нижний HUD игрока скрыт, пока окно открыто.
   - **Загрузка:** если облик занят другим игроком — остаётся текущий; снаряжается облик; профиль сохраняется; инвентарь очищается (проклятые остаются); стартовая реликвия выдаётся (не в PvP); 6 слотов арканов очищаются и 4 аркана ставятся на **те же индексы**, где были базовая/рывок/обычная/фирменная; фирменной ставится флаг; HP до полного.
   - **Сохранение:** текущий облик, стартовая реликвия и 4 аркана; звук затвора; профиль переменных сохраняется при закрытии, если были изменения. При смене стартовой реликвии на закрытии показывается уведомление и звук «усиление».
19. **Хранилище реликвий (сундук-галерея):** 24 на страницу (4×6), 3 категории, счётчик «открыто/всего» на категорию, переключение страниц («ещё (n/N)»), задержка автопрокрутки при удержании 0.25 с / 0.125 с (также в книге арканов).
   - **Выбор стартовой реликвии:** подтверждение на открытой реликвии заменяет стартовую (прежняя удаляется из инвентаря, новая выдаётся), профиль сохраняется, **HP до полного**; закрытая — звук ошибки. Страницы листаются по краям строки (влево с колонки 0 — предыдущая, вправо с колонки 5 — следующая; вверх/вниз — только по строкам внутри страницы). При выборе — анимация полёта иконки 0.15 с в точку (22, −226); «ещё (n/N)» пульсирует таймером 1.25 с; звук смены типа — «открытие сундука», хода по сетке — «шаг»; при закрытии — уведомление о предмете и звук «усиление».

### Магазины

20. Магазин — предметы-пьедесталы в мире, не экран: цена под предметом; при приближении показывается карточка (имя+описание); «Взаимодействие» покупает (кнопка нажатием, не удержанием). Нехватка золота → звук ошибки и отказ продавца; успех → звук покупки, цена заменяется на «×». Скидка: шанс 15%, цена −25 золота (метка красно-розовая; 09 §9). Предмет прячется (затухание 1 с), если враги в радиусе 7 м; покупатель теряется при удалении > ≈3.2 м. Окно «магазина арканов» — устаревший класс-окно (состояния «стихия → аркана → опции → инфо/экипировка», покупка за золото по уровню, «MAX» на максимальном, «экипировать» недоступно при уровне 0, «ульта» только на максимальном уровне); привязан к NPC-магазину и в окончательной игре не достигается (используются стенды хаба). **Для среза не реализуем.**
   - **Хаб-панели** (книга, гардероб, сундук реликвий, лодаут): для игрока 0 занимают **левую половину** экрана (якорь по X 0..0.5), для игрока 1 — правую (0.5..1); в соло панель тоже слева (центральный вариант 0.25–0.75 в коде объявлен, но не вызывается). Лодаут второго игрока зеркалится. Открытие любой панели переводит игрока в «Paused»; панели выезжают за экран: смещение скрытия 300 px по X (к ближнему краю: влево, для правой половины — вправо) или 600 px по Y; в одной группе (на игрока) одновременно идёт только одна анимация перехода.

### Миникарта

21. Сетка уровня режется на секции 4×4 клеток. Секция открывается, когда её триггер пересекает «открыватель» игрока (т.е. при входе в секцию); открытая игроком — белая навсегда; открытая другим источником (локатор) — оттенок (0.5, 0.55, 0.8), позже окрашивается в белый при посещении. Клетки: пол, стена, яма, оверлей; полупрозрачность 0.65. % раскрытия = открытых секций / всех, целым процентом, пересчитывается каждый кадр. Центр камеры миникарты следует за камерой игры. Размер: слайдер 0..1 (по умолчанию 0.5), 0 = отключена; масштаб = 2 × значение; прямоугольник от (0.018 экрана слева) с вертикальным якорем от 0.788 (малая) до 0.188 (большая). **Параметры из префабов** (Источник: data/extra/extra_values.json, minimap, minimap_code_constants): камера миникарты ортографическая, размер 30 м (60 м по высоте); прямоугольник при слайдере 0.5 — левый край 0.018, низ 0.488, ширина 0.18, высота 0.30 доли экрана; фон (0.213, 0.213, 0.213) с прозрачностью 0.176; рисуется только слой «Minimap»; «открыватель» секций вокруг игрока — прямоугольник 20 × 14 м; дистанция раскрытия секции 4 м; полноэкранная камера — размер 110 м, во весь экран.
   - **Генерация секций:** клетка попадает в меш секции, если это пол/стена/яма/оверлей **и** (яма **или** есть соседний по 4-связности пол); приоритет слоя: яма > оверлей > стена > пол; секция создаётся, только если в ней есть хоть одна такая клетка. Открытие триггером ловит объект-«открыватель» с определённым именем; открытая игроком секция выключает свой триггер. Тихое открытие (локатор): оттенок (0.5, 0.55, 0.8), пока игрок не вошёл. Процент — целый процент текущей культуры, пересчитывается каждый кадр, при 0 секций = 0. Размер миникарты (слайдер) применяется и при включении: камера миникарты размер 30, прямоугольник `y = Lerp(0.788, 0.188, слайдер)`. Над миникартой: индикатор этажа (название этапа), % открытия, индикатор врагов (череп). Размеры шрифта этажа/процента и сдвиг иконки черепов зависят от языка (испанский ×1.1 и +24 px; корейский ×0.9 и −72; японский ×0.9 / 1.1 и −72; китайский ×0.9 и −50; французский +10; русский −18; для полноэкранной карты — другие значения).
   - **Маркер игрока:** в соло спрайт (1,1,1,0.0784) и контур (1,1,1,0.11764); в коопе — цвет игрока (HSV: S+0.12, V+0.1, альфа 0.75) и свечение (1,1,1,0.17); поворачивается по вектору ввода (не при паузе/смерти/падении/меню паузы); можно зафиксировать в точке. **Портрет на миникарте:** фон — цвет плаща × 0.4, капюшон — цвет плаща × 1.4; следует за игроком по XY.
22. **Полноэкранная карта:** кнопка «карта» переключает (на паузе и экране загрузки закрыта — принудительно закрывается; **вне сцен этажей ничего не происходит**: обработчик завершается раньше чтения кнопки, звука ошибки нет). Центр = 0.5 × начало + 0.25 × (средняя позиция сетки + позиция камеры). Показывает порядок этапов (до 5 иконок стихий — по числу этапов забега), название этапа, %. Открытие прячет компас и миникарту (запоминает, была ли миникарта включена); закрытие возвращает миникарту, только если она была включена и сцена — этаж.
23. **Компас:** стрелки-указатели вокруг игрока. В префабе настроено **11 указателей**: выход, продавец реликвий, продавец арканов, особая комната (общая), проклятая лавка, пиньята-комната, медсестра, слоты, коллекционер, портной, банкир; общий тип «особая комната» из триггера указатель не активирует — рабочих указателей 10. Типы «аркана», «реликвия», «лечилка», «старт», «сундук» указателя не имеют (только иконка на миникарте). Дистанция стрелки от центра = `Lerp(1, 24, clamp(dist / 24 × 0.75, 0, 1))` (достигает 24 при dist ≥ 32); скрыта при dist ≤ 10 м; стрелка повернута к цели; центр компаса следует за камерой. В гонке боссов указатели не включаются; все указатели деактивируются при загрузке уровня. **Параметры (все настроенные указатели одинаковы):** максимальная дальность стрелки 24 м, минимальная 1 м, стрелка скрыта ближе 10 м до цели; триггер-зона указателя 3 × 3 м (Источник: data/extra/extra_values.json, compass, compass_code_constants). «Стартовая комната 2.75 с» в оригинале — не время показа: 2.75 — масштаб иконки старта на миникарте, по времени компас ничего не показывает.
   - **Флаги находок и направленные порталы.** Активация указателя выставляет флаги уровня «выход найден», «магазин реликвий найден», «магазин арканов найден», «особая комната найдена»; деактивация указателя сбрасывает флаг. Пока выход **не** найден, находка магазина реликвий/арканов/особой комнаты создаёт **обратный направленный портал** на точке выхода из этой комнаты, цвет по типу, ведущий в стартовую позицию этажа; нахождение выхода гасит все направленные порталы и новых не создаёт (07/08/11/18 механику не описывают — решение по срезу: не реализуем, в 07 пометить как открытый вопрос).

### Итоги

24. **Итог этажа:** пауза мира; панель: время (мин:сек.сотые), % карты (или «--», если миникарта отключена), золото и кристаллы этажа; блок на игрока: урон = базовыми + арканами, убитые × 25, бонус здоровья (в референсе формула всегда ≤ 0 — считаем дефектом: наш бонус = `ceil(500 × (1 − полученный/макс. HP))` со знаком, как в 13 §8), бонус экономии = 500 × (1 − потрачено/сумма потрачено), (+500 победителю PvP); итог ≥ 0. В коопе корона лучшему через 0.5 с; ничья — обоим. «Продолжить» доступна через 1.5 с.
25. **Итог забега (смерть или победа):** фон 0.5 с; затем по строкам с шагом 0.1 с: заголовок (смерть/победа), метка «этап-этаж» (префикс «+» если сложность > 0, звёздочка при победе над фазой «Сверх»), кристаллы забега, время; для гонки боссов — таблица отметок по боссам (шаг 0.07 с); затем сборка каждого игрока: облик (поза смерти/победы), 7 арканов (6 + запасной; рамка фирменная/усиленная/обычная), до 12 реликвий (проклятые — красноватый фон); кнопки «Подтверждение» (в комнату игрока, из титров — в эпилог) и «Отмена» (на титул; в титрах нет).
   - **Тайминг и детали:** первая строка появляется через **1.0 с** после старта (фон 0.5 с + пауза 0.5 с; при переопределённом времени фейда — сразу по его окончании); шаг строк 0.1 с, таблица отметок гонки боссов 0.07 с. Победа = «не все игроки мертвы»; поза и звание заголовка зависят от победы. Подтверждение читается у **любого** активного игрока, иконки — по схеме игрока 0. После выбора — загрузка сцены и **полный сброс статистики уровня**. Цвета подложек реликвий: обычная (0.176, 0.176, 0.176) с контуром (0.337, …); проклятая (0.208, 0.110, 0.110) с контуром (0.388, 0.220, 0.220); рамка арканы — фирменная/усиленная/обычная; в соло блок второго игрока не загружается.

### Загрузка, телеграф, иконки

26. **Экран загрузки:** чёрный оверлей; подсказка мерцает по альфе 0.6 ↔ 1 (смена каждые 0.5 с, кроссфейд 0.25 с); счётчик петель «x{n+1}» при петле > 0; курсор скрыт. По окончании загрузки — анимация телепорта, ожидание 25 % её воспроизведения, затем появление игроков, показ названия этапа и конец загрузки.
   - **Доска прогресса** (при переходах между этапами): 3 яруса стихий × (2 уровня + босс) + старт + финал; в гонке боссов — по 2 узла на ярус (уровень + босс). Фишки игроков идут по линии за 1.5 с с паузой 0.25 с до и после; в коопе смещение фишек (15, −15) и (−15, 15), фишка игрока 1 идёт с опережением 0.33 по прогрессу; «корона» у лидера по числу этажей (ничья — обоим; не в гонке боссов; только после первого этажа); пройденные узлы затемняются (0, 0, 0, 0.66); при петле фишка стартует с финального узла; fade всей доски 0.25 с; конец загрузки ждёт окончания движения.
27. **Линия прицела / телеграф** (общий класс для аркан игрока и атак врагов: лучники, босс воздуха, финальный босс, шары, фамильяры, лазеры): линия от начальной точки со смещением (0; 0.5); длина = максимальная дальность (по умолчанию 20) минус обрезка по ближайшему препятствию (верхняя стена/препятствие; опционально разрушаемые и враги из списка целей); проверка 3 лучами — центральным и двумя боковыми со смещением перпендикулярно ±толщина × 0.51; цели с «проходимой» атакой не обрезают; есть минимальная дальность и поправка на запас; толщина по умолчанию 0.25 (минимум 0.0625); бегущая точка по линии со скоростью 10 м/с с заворотом на длину; направление — вектор прицела игрока или направление взгляда. **Телеграф врага:** прозрачность растёт `0.6 × прогресс таймера` до 80 %; на 80–90 % мигает между красным (0.8, 0, 0) и белым (1, 1, 1, 0.75) каждые 0.018 с; ≥ 90 % — сплошной красный, альфа 1.
28. **Иконки подсказок.** Выбор схемы: клавиатура или (по типу геймпада) Xbox / PS / Switch. Слоты 0..5: Xbox — синяя, зелёная, жёлтая, красная, левый бампер, правый бампер; PS — квадрат, крест, треугольник, круг, L1, R1; Switch — Y, B, X, A, L, R. Ульта: правый триггер / R2 / ZR / Shift. Меню снаряжения: левый триггер / L2 / ZL / клавиша раскладки. Подтверждение: зелёная / крест / B / пробел. Отмена: красная / круг / A / Escape. Взаимодействие: синяя / квадрат / Y / клавиша раскладки. Карта — нажатие правого стика во всех трёх. Подписи клавиш берутся из профиля раскладки; мышь «M0..M5», префиксы Alpha/Keypad отрезаются; неизвестная клавиша — иконка-заглушка. Запасные иконки: неизвестная аркана, предмет, картина — заглушка; неизвестный спрайт мага — случайный; рамка КД по типу (2 золотая, 1 бирюзовая, иначе неактивная). Валидация профиля раскладки при загрузке — 26.
29. **Метка цены:** спрайт по типу валюты (золото / кристаллы), тень, слой сортировки привязан со смещением к предмету. Отдельных экранов по классам выбора персонажа (29), гардероба (16/17), истории забегов и стеллажа трофеев (28), музейных табличек (27/29) здесь нет — они описаны в своих спеках.

## Критерии приёмки

- Тест HUD-модели: HP 100→60: заливка сразу 0.6, след сразу начинает убывать с 1.0 со скоростью 25 HP/с (40 HP за 1.6 с), без паузы-удержания; вторая рана в процессе не переустанавливает след.
- Перезарядка 12.3 с показывает «12», 12.6 — «13», 9.87 — «9.9», 9.96 — «10.0»; готов → пинг ≤ 1 раз в 0.5 с; переход Cooldown → NotReady тоже пингует.
- Счётчик черепов: при доле 0.15 заливка первого = 0.5 (1 − 0.15/0.3); при пересечении 0.3 гаснет череп с индексом 2; пересечение двух порогов за один кадр гасит только один череп в этом кадре.
- Уведомления: 25 одновременных — все показываются по очереди (предела нет); дубликат ожидающего по имени не добавляется, дубликат показываемого — добавляется; следующее стартует на 80 % анимации.
- Хаб-панель игрока 0 и 1 в коопе — разные половины экрана; в соло — левая.
- Компас: dist = 5 → скрыта; dist = 32 → расстояние стрелки 24; dist = 16 → 12.5; тип «аркана» указателя не создаёт.
- Карта вне этажа: нажатие ничего не делает, звука нет.
- Выбор лодаута: аркана базовой атаки, рывка, обычная и фирменная возвращаются в те же индексы слотов; HP полное.
- Миникарта: вход в секцию открывает её и меняет % ровно на 1/N; повторный вход не меняет; локатор открывает оттенком, посещение — белым.
- Пауза: 4 пункта, зацикливание вверх/вниз; «выйти» не срабатывает без подтверждения; по умолчанию в подтверждении «отмена».
- Итог этажа: убитых 10 → 250 очков; не уходит ниже 0.
- Скриншот каждого экрана (CLAUDE.md п.9).

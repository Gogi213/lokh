# 26 — Ввод и настройки

## Цель

Единый слой ввода: игровые действия, раскладки клавиатура+мышь и геймпад, ремап, режимы прицела, назначение устройств игрокам; и меню настроек с диапазонами и значениями по умолчанию. Слой ввода пишет только «намерения» в симуляцию (вектор движения, вектор прицела, нажатия действий); симуляция устройств не знает.

## Поведение

### Действия

1. **Игровые:** движение (две оси: горизонталь/вертикаль), аркана-слот 0..5 (6 слотов; слот 0 — базовая атака, слот 1 — рывок, 2 — вторая атака, 3–5 — дополнительные/фирменная по билду), ульта (отдельная кнопка, активируется удержанием; работает только когда шкала готова, игрок не в воздухе, не в состоянии смерти/падения/заморозки/паузы), взаимодействие, меню снаряжения, карта, пауза («меню»).
2. **Интерфейсные:** подтверждение, отмена, четыре направления (по осям движения; нажатие, а не удержание — одно срабатывание на нажатие, повтор запирается до отпускания). UI принимает ввод от любого устройства любого игрока (включая «системного» игрока без привязки).
3. **Запросы к устройству:** нажатие / удержание / отпускание действия; вектор движения (нормализованный; диагонали не быстрее); вектор прицела.

### Раскладки по умолчанию

| Действие | Клавиатура/мышь | Геймпад (Xbox-раскладка; PS/Switch — по соответствию физических позиций) |
|---|---|---|
| Движение | W / A / S / D | левый стик |
| Слот 0 (базовая атака) | ЛКМ | левая лицевая кнопка (X) |
| Слот 1 (рывок) | Пробел | нижняя (A) |
| Слот 2 | ПКМ | верхняя (Y) |
| Слот 3 | Q | правая (B) |
| Слот 4 | E | левый бампер |
| Слот 5 | R | правый бампер |
| Ульта | Shift | правый триггер |
| Взаимодействие | F | левая лицевая (X) |
| Меню снаряжения | Tab | левый триггер |
| Карта | M | нажатие правого стика |
| Подтверждение / Отмена | Пробел / Esc | нижняя (A) / правая (B) |
| Пауза | Esc | Start |

Примечание: Слот 0 и «взаимодействие» на геймпаде делят кнопку — они не конфликтуют, потому что вне зоны объекта взаимодействия нет. Иконки подсказок (HUD, 25) берутся из таблицы «действие × схема × тип геймпада»; тип геймпада (Xbox / PS / Switch) выбирается настройкой, схема (клавиатура/геймпад) определяется автоматически.

### Устройства и схема

4. У каждого игрока (0, 1) и «системного» есть набор контроллеров. В соло все контроллеры отдаются игроку 0 (клавиатура+мышь и все геймпады одновременно). В коопе/PvP игроку 0 и 1 назначается по одному устройству; игрок 1 на геймпаде — игрок 0 получает клавиатуру+мышь, если у него нет клавиатуры.
5. **Автосмена схемы:** по последнему активному устройству игрока: нажатие на геймпаде переключает схему «геймпад», нажатие клавиши/мыши — «клавиатура» (подсказки меняются на лету). Опция «блокировать ввод» (lock input) отключает автосмену и перехват устройств.
6. **Отключение геймпада** активного игрока в игре ставит игру на паузу (запрос паузы). Подключение: если у игрока 0/1 нет устройств, а он в игре — получает свободное; иначе устройство уходит системному игроку.
   - **Правила назначения (референс).** Старт: все контроллеры отданы системному игроку. Захват устройства игроком: если игрок 0 не в коопе/PvP и блокировка ввода выключена — **все** остальные контроллеры отходят к нему (пара клавиатура+мышь переносится вместе); для игрока 1 при захвате не-клавиатурного устройства и отсутствии клавиатуры у обоих — клавиатура+мышь отдаётся игроку 0. «Свободное устройство» = не привязано ни к игроку 0, ни к 1 (системный игрок не учитывается). Подключение: переприсвоить прежнему владельцу; иначе игроку (0/1), у которого нет устройств и который в игре; в соло игрок 0 получает всё; иначе — системному. Отключение: если это основное устройство игрока и пауза не открыта — запрос паузы; затем игрок без устройств получает свободное (если блокировка ввода выключена). Блокировка ввода влияет на захват и отключение, **не на подключение**. UI читает ввод у всех трёх наборов (любое устройство). Схема по умолчанию — «геймпад», пока устройство не захвачено. (В референсе присвоение пары клавиатура+мышь использует статическую переменную вместо аргумента — не копировать: пара всегда идёт вместе.)

### Прицел

7. **Мышь-прицел (по умолчанию вкл.):** прицел = единичный вектор от точки атаки игрока к курсору в мире. Вектор прицела от дистанции не зависит. Если курсор ближе 2.25 м (для некоторых арканов — квадрат 5 м²), шаг вперёд во время удара/движения арканы не делается; направление удара остаётся по курсору. Работает только при схеме «клавиатура».
8. **Рывок к мыши (по умолчанию выкл.):** рывок идёт к курсору, а не по вектору движения. Включение автоматически включает мышь-прицел; выключение мыши-прицела автоматически выключает рывок к мыши.
9. **Геймпад:** прицел = вектор движения (левый стик, нормированный). Опция «блокировка прицела» (lock aim): при отпущенном стике прицел сохраняет последнее ненулевое направление; иначе при нулевом стике прицела нет (аркана берёт направление взгляда персонажа). Сохранённый вектор **не очищается** при смене схемы/сцены. Класс настроек по умолчанию имеет «lock aim» = вкл, профиль — выкл; после загрузки настроек побеждает профиль. Блокировка ввода отключает автосмену схемы (проверка при каждом запросе ввода).
   - **Мышь-прицел:** вектор = нормаль(мир(курсор) − точка атаки игрока), нулевой при точном совпадении; к вектору последнего движения **не** обновляется; то же для рывка к мыши; работает только при схеме «клавиатура». Нормаль движения: диагонали нормируются.
10. **Мёртвая зона / кривая стика:** в референсе заданы внешним пакетом ввода и в коде не видны. Наш выбор: радиальная мёртвая зона 0.2, затем перемасштабирование 0..1 (параметр в `data/*.json`).

### Ремап (меню «раскладка»)

11. Окно ремапа содержит **17 строк**: 4 направления, 6 слотов, взаимодействие, меню снаряжения, карта, переключатель мыши-прицела, переключатель рывка к мыши, «по умолчанию», «назад». Ульты нет (фиксирована: Shift / триггер). Навигация вверх/вниз с заворотом, звук «шаг»; поддержаны наведение и щелчок мыши.
12. Процесс: выбрать поле подтверждением → окно «нажмите клавишу»; записывается первая (в порядке перечисления клавиш) из нажатых в кадре, **кроме** Esc, Enter и любых кнопок джойстика; Esc (по отпусканию) закрывает окно без изменений; выход занимает ещё один кадр, затем навигация блокируется до отпускания. Назначение той же клавиши другому действию: конфликтное действие теряет привязку; исключения — подтверждение, отмена, пауза и оси движения на стрелках не затираются; пробел может быть одновременно слотом 1 и подтверждением (по умолчанию так). Назначение на кнопку мыши удаляет конфликтующие привязки **в карте мыши** без исключений (включая подтверждение/отмену). Допустимые кнопки мыши: 0–5 (включая боковые). Назначение применяется ко всем трём наборам игроков (0, 1, системный). Строка «по умолчанию» сбрасывает клавиши и оба тумблера (аим вкл, рывок выкл) и обновляет иконки HUD.
   - **Привязки.** Стрелки остаются **постоянными дополнительными привязками** движения и навигации по UI: ремап направления удаляет только привязки того же полюса, стрелки не удаляет. При назначении сначала удаляются **все** привязки этого действия (клавиатура+мышь; у осей — полюс).
   - **Сохранение:** значения читаются **из живых карт** (потерянная привязка — «нет»); для направлений читается клавиша своего полюса, при выборе предпочтительнее не-стрелка. **Загрузка:** сначала загружаются карты по умолчанию (стрелки и геймпад), затем применяются 13 сохранённых клавиш. Проверка перед применением: наличие ключей слотов 0–5, взаимодействия, меню и карты; движение **не проверяется**; при провале сбрасывается всё (включая оба переключателя мыши). Изменения сохраняются при выходе из меню.
13. Геймпад не ремапится (фиксированная раскладка + выбор рисунка). В данных референса есть две схемы геймпада (тип А — таблица выше; тип Б: меню снаряжения на левом бампере, карта на правом, слоты 4/5 на триггерах) и схема одиночных боковых джойконов Switch в коопе (грани: слот 0 вверх, 1 влево, 2 вправо, 3 вниз; боковые — слоты 4/5). Это **декоративная накладка**: нигде не вызывается и действий не меняет; для среза не реализуем — действия геймпада фиксированы (тип А).

### Курсор мыши и общие правила UI-ввода

13б. **Курсор:** игровой курсор — картинка, следующая за мышью; системный скрыт. Через 10 с без движения и нажатий (игровое время) курсор скрывается; любое движение или нажатие любой из трёх кнопок возвращает; на экране загрузки таймер простоя не идёт, курсор скрыт. Курсор заперт в окне (confined); этот режим **заново выставляется через 2 кадра** после получения фокуса окном, смены разрешения и смены полноэкранного режима. Переключатель «системный курсор»: вкл — системный курсор виден, игровой выключен.
13в. **Направления для UI** — события положительной/отрицательной стороны осей (Вверх = положительная вертикальная, Влево = отрицательная горизонтальная). Меню с аналоговой навигацией (снаряжение, реликвии, окно опций окна магазина) используют порог стика 0.3 на нажатие и 0.2 на отпускание (0.04 / 0.09 по квадрату — в панели облика). «Подтверждение/отмена/меню» в UI читаются со всех игроков.
13г. **Пауза — активация:** открытие — «Меню» (нажатие) любого игрока; для геймпад-игрока работает и Esc (запасной путь, только когда нет клавиатурных игроков); закрытие — отпускание «Меню» или «Отмена» (флаг не даёт закрыть тем же нажатием, которым открыто). Запрещено: все игроки мертвы, итог этажа активен, экран загрузки (откладывается), сцена титров (25 п.13).

### Меню настроек (18 строк, индексы 0–17; навигация вверх/вниз с зацикливанием, лево/право меняют значение)

| # | Пункт | Тип / диапазон | По умолчанию | Эффект |
|---|---|---|---|---|
| 0 | Разрешение | список всех режимов | текущее | применяется подтверждением |
| 1 | Полный экран | вкл/выкл | текущее | |
| 2 | Яркость | 0..1, шаг 0.01 за кадр удержания | 0.5 | глобальный окружающий свет = значение × белый |
| 3 | Вертикальная синхр. | вкл/выкл | выкл | |
| 4 | Системный курсор | вкл/выкл | выкл | вкл — скрыть игровой курсор |
| 5 | Музыка | 0..1 | 0.5 | шина BGM (формула дБ в 24); музыка играет только на этом пункте |
| 6 | Звуки | 0..1 | 0.5 | шина SFX; звук «шаг» при движении ползунка |
| 7 | Тряска камеры | 0..1 | 0.5 | множитель силы = 2 × значение (0 — выкл, 0.5 → ×1) |
| 8 | Размер миникарты | 0..1 | 0.5 | 0 — миникарта выключена (25) |
| 9 | Цифры урона | вкл/выкл | вкл | |
| 10 | Тип геймпада | 0 Xbox / 1 PS / 2 Switch, зацикл. | 0 | иконки подсказок |
| 11 | Блокировка прицела | вкл/выкл | выкл | |
| 12 | Блокировка ввода | вкл/выкл | выкл | |
| 13 | Язык | список (27) | английский | требует подтверждения (формулировка «третий»), перезагружает титул |
| 14 | Раскладка | открывает окно ремапа | | |
| 15 | Сброс данных | 3 подряд подтверждения | | сброс профиля и перезагрузка с начальной загрузки |
| 16 | По умолчанию | кнопка | | сбрасывает яркость, музыку, звуки, тряску, миникарту, цифры; сохраняет |
| 17 | Назад | | | сохраняет и закрывает |

Сохранение настроек — при **любом** закрытии меню (пункт 17 или отключение объекта); при закрытии миникарта возвращается в прежнее состояние.
   - **Применение значений:** тип геймпада, язык и разрешение: лево/право меняют **временное** значение (тип/язык — с заворотом по списку; тип `(v + 3) mod 3`), применение — по «Подтверждению» (язык ещё требует окна «третье»). Полный экран: «Подтверждение» мгновенно пересоздаёт окно с текущим разрешением и инвертирует режим. Вертикальная синхронизация — счётчик 1/0, применяется сразу и при открытии меню. Язык: список в порядке английский, испанский, китайский, японский, корейский, французский, немецкий, русский, разработческий; после подтверждения загружаются словари и диалоговые реестры, меню закрывается, загружается титул. Сброс данных: 3 подряд окна подтверждения с заголовками «первое/второе/третье»; затем флаг; родитель (пауза/титул) загружает начальную загрузку. «По умолчанию»: яркость, музыка, звуки, тряска, миникарта = 0.5, цифры = вкл; **не** трогает полноэкранный, vsync, системный курсор, геймпад, оба lock, язык, раскладку; сохраняет. Ползунок «миникарта» ≤ 0 выключает миникарту, иначе включает, задаёт размер 30 камеры миникарты и прямоугольник (25).
   - **Ползунки** читают **удержание** направления каждый кадр: скорость зависит от частоты кадров (при 60 к/с 0.6/с, весь диапазон ≈ 1.7 с; наш выбор: в тиках симуляции, 0.6/с). Навигация вверх/вниз и переключатели — по событию «нажато» (одно срабатывание, блокировка до отпускания). Список разрешений — все режимы экрана (дубликаты с разной частотой не склеиваются); начальный индекс — совпадающий с текущим, иначе 0. Звук «шаг» при движении ползунка SFX — через событие изменения значения, только на строке «Звуки».
   - **Известная ошибка референса (не копировать):** индикатор «lock input» при открытии перезаписывает индикатор «lock aim». Хранится: полный экран, яркость, громкости, тряска, размер карты, цифры, тип геймпада, оба lock, vsync, системный курсор, раскладка, оба тумблера мыши, язык.

## Критерии приёмки

- Раскладка по умолчанию воспроизводит таблицу; подсказка слота 3 на геймпаде PS показывает круг, на Xbox — правую кнопку.
- Ремап: назначить Q на слот 5 → слот 3 теряет привязку; назначить Esc отменяет без изменений; сброс возвращает таблицу.
- Мышь-прицел при курсоре в 2 м от героя не двигает героя к курсору; в 4 м — двигает.
- Включить «рывок к мыши» при выключенном «мышь-прицел» → оба включены; выключить прицел → рывок выключен.
- Фикстура: ползунок музыки 0 → −80 дБ; 0.5 → −5; тряска 0.5 → множитель 1.0.
- Блокировка прицела: отпустили стик → вектор прицела прежний; выключена → нулевой.
- Ремап: окно содержит 17 строк с заворотом; Enter/Esc/кнопка джойстика не записываются как клавиша; назначение клавиши на мышь удаляет конфликт даже у подтверждения; ремап «W» на движение вверх не удаляет стрелку «вверх»; загрузка профиля без ключа слота 3 → полный сброс (включая тумблеры), без ключа движения → применяется.
- Устройства: в соло все контроллеры у игрока 0; игрок 1 захватил геймпад, клавиатуры нет → клавиатура+мышь у игрока 0 вместе; подключение геймпада при игроке без устройств → ему; отключение основного устройства → запрос паузы.
- Курсор: 10 с без движения → скрыт; любое нажатие → виден; на загрузке скрыт.
- Меню настроек: «по умолчанию» не меняет язык, vsync, полноэкранный; закрытие любым способом сохраняет; язык применяется только по подтверждению.
- Скриншот меню настроек и ремапа.

# 00 — Глоссарий: единые термины спецификации

Один канонический русский термин на понятие. Все файлы `00`–`30` (включая `05b`, `05c`, `15`, `15b`, `coverage.md`) используют только термины из этого файла. Идентификаторы референса живут исключительно в колонках и строках «Источник»; имена арканов, врагов и реликвий — свои (описательные), не переводы внутренних ID. Ключи схем данных (`overdrive{}`, `od_gain_mult`, `archetype`, `spell_list` и т. п.) остаются английскими: это имена полей, а не термины текста; соответствие — в колонке «Поле данных».

Формат строки: **термин** — определение; *не использовать* — запрещённые синонимы.

## 5. Стихии

Шесть стихий: **огонь**, **вода**, **воздух**, **земля**, **молния**, **хаос**. Не использовать: холод, ветер (как стихию), гроза. Подстихии: **лёд** (у воды; цвет и заморозка), **яд** (у земли; статус яда), **растение** (у земли; корни). Статусы по стихиям: огонь — поджог, вода — заморозка, воздух — замедление, земля — яд (+ корни у растений), молния — шок, хаос — хаос-статус или все статусы (04, 05 §6). Цепочка уязвимостей: вода > огонь > воздух > земля > молния > вода (04 §18). Коды в нумерации 05c: ОГ, ВД, ВЗ, ЗМ, МЛ, ХА.

## 6. Архетипы арканов (единый перечень)

Поле `archetype` ∈ перечня из 12 значений плюс `service` (не аркана); `subtype` — из списка своего архетипа. Слияния, принятые при сведении 15+ архетипов 05c: `throw`/`boomerang`/`barrage`/`roller`/`pendulum`/`bomb` → `projectile`; `wave`/`wall`/`field`/`trap`/`pillars`/`aura`/`blast`/`burst`/`drop`/`grab`/`chain_strike`/`line_strike` → `zone`; `minion`/`familiar`/`turret`/`decoy`/`weapon_summon` → `summon`; `orbital` → `ward`; `lunge`/`melee_strike`/`channel_dash`/`teleport` → `rush`; `spin` → `channel`; `portal`/`anchor` → `special`; `status_tick`/`item`/`parry_effect` → `service`.

## Критерии приёмки

- Headless: реплей из 3000 тиков с фиксированным сидом и пустым вводом даёт одинаковый хеш при двух запусках и разный при двух сидах.
- Headless: недопустимый переход автомата (`TITLE`→`BOSS`) отклоняется; допустимые проходят.
- Headless: JSON с битой ссылкой роняет загрузку и печатает все ошибки разом.
- Headless: событие, порождённое обработчиком 9 раз подряд, даёт ошибку глубины; 8 — проходит.
- Headless: сохранение с повреждённой основной копией читается из предыдущей; файл старой версии мигрирует.
- Headless: два запроса перехода подряд (в окне ожидания и во время `LOADING`) приводят к одной загрузке — первого имени сцены.
- Headless: мировая пауза не открывается при всех мёртвых (без реликвии возрождения), на экране итогов, во время загрузки и в сцене титров; закрывается по отпусканию, первое отпускание после открытия не закрывает; пауза во вр
- Headless: очередь хитстопов: запрос 0.35 с при остатке 0.2 с даёт остаток 0.55 с, запрос 0.1 с при остатке 0.2 с остаток не меняет; снятие паузы во время хитстопа возвращает прежний множитель.
- Headless: взвешенный выбор с весом 0 не выпадает ни разу на 100 000 бросков; пустой набор возвращает «ничего»; один сид — одна последовательность.
- Headless: секундомер: «закончен» при отсутствии записи; «добавить к остатку» создаёт запись; интервальный таймер с первой зарядкой ≤ 0 отдаёт «готово» сразу; запись на паузе удаляется через 300 с.
- Headless: смена состояния сущности на то же имя игнорируется, кроме имён «урон» и «заморозка»; два запроса смены за кадр — применяется последний, до обновления состояния.
- Headless: «главное направление» (3, 3) = нейтраль; направление 22.4° и 22.6° попадают в разные сектора; формат времени 59.999 → `59.99`, 61.5 → `1:01.50`.
- Headless: перечисление стихий: «подстихия» верно для льда, растения, яда и неверно для нейтрали и хаоса.
- Визуально: пустая комната на ортокамере, при 30/60/144 Гц кадра ход симуляции одинаков (скриншот счётчика тиков), пауза замораживает сцену.
